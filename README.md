SDC330 Final Project – Vehicle Management System

This project demonstrates object-oriented programming concepts along with SQLite database integration.

Features:
- OOP concepts: abstraction, inheritance, composition, polymorphism
- Vehicle management system
- SQLite database integration
- CRUD operations (Create, Read, Update, Delete)

The program runs in the terminal and shows both object behavior and database functionality.

GitHub tracks the full development process across multiple project phases.
